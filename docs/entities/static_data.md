Use these entities for the next race, calendar, circuit weather, championship standings, and completed results. Each link opens the complete state and attribute reference for that entity.

Schedule timestamps can include UTC (`race_start_utc`), Home Assistant local time (`race_start`), and circuit local time (`race_start_local`). Choose the variant that matches your dashboard or automation.

:::info[Entity IDs and display names]
The links use standard entity IDs. Display names can be translated, and older or renamed entities may have different IDs. Select the entity from your installation when copying an example.
:::
