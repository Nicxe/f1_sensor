F1 Sensor translations are maintained in Hosted Weblate. You can translate directly in your browser, improve an existing language, or fund an AI-assisted first pass and focus your time on review and refinement.

## Choose how to help

You do not need to sponsor F1 Sensor to contribute a translation. Choose the path that suits you:

- **Translate in Weblate** when you want to write or review the text yourself.
- **Use the AI-assisted start** when a language needs a first pass or has many untranslated strings and you would rather focus on natural wording and terminology.

Both paths use the same community translation workflow. English remains the source language, and incomplete translations fall back to English until translated text is available.

## Translate in Weblate

1. Open the [F1 Sensor project in Hosted Weblate](https://hosted.weblate.org/engage/f1-sensor/).
2. Choose the language you want to translate or review.
3. Select a component and open its untranslated or suggested strings.
4. Translate the meaning of the English source text rather than copying its word order.
5. Save your work in Weblate and continue with the next string.

If your language or regional variant is not listed, [start a GitHub Discussion](https://github.com/Nicxe/f1_sensor/discussions/new?category=general). Include the language name and locale code if you know it, such as `pt-BR` for Portuguese (Brazil).

:::tip
You can also improve a language that is already available. Corrections to terminology, tone and regional wording are just as useful as translating a new string.
:::

## Get an AI-assisted first pass

The optional AI-assisted path lets an external translation service do the heavy lifting at the beginning. It can create a first pass for a new language or fill a substantial gap in an existing one. A human speaker can then spend time on the parts where judgment matters: natural phrasing, Formula 1 terminology, Home Assistant wording and regional usage.

The one-time sponsorship helps cover the external translation API cost. It does not make AI output final or remove the need for community review.

### Request an AI-assisted translation

1. Open the [F1 Sensor GitHub Sponsors page](https://github.com/sponsors/Nicxe).
2. Choose **One-time** and select **Add or complete a language for F1 Sensor**.
3. Complete the sponsorship.
4. Follow the link in the welcome message to start a GitHub Discussion.
5. State which language or regional variant you want added, completed or improved. Include the locale code if you know it.
6. Wait for confirmation of the current Weblate status and the scope of the translation.

The maintainer reviews the English source and any existing translation first. The AI-generated text then enters the normal translation workflow as a starting point, where it can be reviewed and corrected in Weblate before it reaches users.

:::info
The sponsorship covers one initial AI-assisted pass for the agreed language scope. It does not guarantee perfect wording or ongoing automatic translation when new English text is added.
:::

## Review an AI-assisted translation

AI is useful for coverage, but it can miss context. When you review its work:

1. Check that the translation sounds natural to a native speaker.
2. Keep Formula 1 and Home Assistant terminology consistent.
3. Confirm that short labels still make sense in cards and Home Assistant controls.
4. Preserve placeholders, numbers and formatting from the English source.
5. Correct regional wording when the language has multiple common variants.

If a phrase is ambiguous, use the Weblate discussion tools or [start a GitHub Discussion](https://github.com/Nicxe/f1_sensor/discussions/new?category=general) before guessing.

## When translations become available

Weblate sends translation updates through the same review and validation path as other F1 Sensor changes. Approved translations are included in a later F1 Sensor release; saving a string in Weblate does not update an installed integration immediately.

Missing text continues to use the English source, so an incomplete language can be improved gradually without blocking the rest of the integration.
