Check [troubleshooting](/help/overview) first. If you need help, choose a channel below and include the context that makes your setup understandable.

## Found a bug?

[Open a GitHub issue](https://github.com/Nicxe/f1_sensor/issues/new/choose). Include the installed versions, live/replay mode, steps to reproduce, expected behavior and actual behavior. For a card problem, choose **Live data card** and attach an image if it helps. [Collect debug logs](/help/debug-logging) before reporting a repeatable error.

Report suspected security vulnerabilities privately using the [security policy](https://github.com/Nicxe/f1_sensor/security/policy). Do not publish tokens or pairing URLs.

## Have a feature request?

Share the problem you want to solve in [Ideas](https://github.com/Nicxe/f1_sensor/discussions/categories/ideas), with an example of how you would use the feature.

## Have a question?

Use [GitHub Discussions](https://github.com/Nicxe/f1_sensor/discussions) or the [Home Assistant community topic](https://community.home-assistant.io/t/formula-1-racing-sensor/880842). Mention the feature and your installed version.

If you want to improve a page, use **Edit this page** or read [CONTRIBUTING](https://github.com/Nicxe/f1_sensor/blob/dev/CONTRIBUTING.md).
